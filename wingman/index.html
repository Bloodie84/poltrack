Réglages

Aide IA (Claude)

Sans clé, l'app marche quand même : le moteur local écrit des suggestions à partir de modèles de phrases. Avec une clé API Anthropic, les réponses sont écrites sur mesure à partir de la conversation, de son profil et de ton style.

La clé est stockée en clair dans le localStorage de ce navigateur et part directement de ton navigateur vers api.anthropic.com. N'utilise cette page que sur un appareil qui est à toi, et ne publie jamais cette page en ligne avec ta clé dedans.

Elle se crée sur console.anthropic.com → API keys. Usage facturé à la consommation.
